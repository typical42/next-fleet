# The primary user is a freelancer, not a fleet manager

NextFleet is built for a freelancer or small business with one to five vehicles. The private car
owner is already served by two Nextcloud apps, and the company fleet manager brings roles, pool
bookings, handover protocols and employee-data law with them. The freelancer is the only user for
whom the differentiator — a tax-grade logbook, gap detection, a mileage claim — is worth switching
apps for. Everything multi-driver stays behind v1; the access check ships from the first commit
anyway because it cannot be retrofitted.
