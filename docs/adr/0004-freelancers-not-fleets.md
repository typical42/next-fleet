# The primary user is a freelancer, not a fleet manager

NextFleet is built for a freelancer or a small business with one to five vehicles.

Two Nextcloud apps already serve the private car owner.
The company fleet manager brings roles, pools, handovers and employee-data law.
Only for the freelancer is the difference, a logbook the tax office accepts with gap detection and a mileage claim, worth switching apps for.

The access check ships from the first commit anyway, because it cannot be added later.
