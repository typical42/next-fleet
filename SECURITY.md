# Security

Report a vulnerability privately through GitHub's private vulnerability reporting:
<https://github.com/typical42/next-fleet/security/advisories/new>. Never in a public issue.

You get a first reply within 14 days. Once the report is confirmed, the fix ships in the next
release, and the advisory is published with it. Say if you want credit; you get it in the advisory
and in the changelog.

This is a third-party app: it is not covered by Nextcloud's own bug bounty. What we do about which
threats is in [docs/security.md](docs/security.md).
